# 数据中心管理系统

这是一个用于管理数据中心设备、机柜和连接关系的综合管理系统。系统提供了直观的界面来管理设备实例、机柜布局、设备连接以及机柜面板视图。

## 主要功能

系统包含四个主要功能模块：

### 1. 设备管理

设备管理模块提供全面的设备生命周期管理功能：

- **设备实例管理**
  - 添加单个/批量设备实例
  - 编辑设备信息
  - 删除设备
  - 批量导入设备（支持 CSV 格式）

- **设备型号管理**
  - 定义新设备型号
  - 配置设备接口组
  - 设置设备高度（U数）
  - 管理接口命名规则

- **设备状态管理**
  - 设备上架/下架
  - 电源管理（上电/下电）
  - 批量操作支持

- **筛选和搜索**
  - 按机房筛选
  - 按机柜筛选
  - 按设备型号筛选
  - 按状态筛选
  - 设备名称搜索

### 2. 连线工具

连线工具模块用于管理设备间的连接关系：

- **设备连接管理**
  - 创建设备连接
  - 管理连接端口
  - 可视化连接关系

- **设备组管理**
  - 创建设备组（如 MLAG 组）
  - 管理组内设备关系
  - 自动配置组连接

- **端口模板**
  - 管理端口模板
  - 自动应用模板配置
  - 支持多种连接类型

### 3. 机柜管理

机柜管理模块提供机柜空间和设备布局管理：

- **机柜布局**
  - 管理机柜位置
  - 设备上架位置规划
  - U位空间管理

- **机房管理**
  - 机房信息维护
  - 机柜分布管理
  - 空间利用率统计

- **设备分布**
  - 查看机柜设备分布
  - 管理设备位置
  - 优化空间利用

### 4. 机柜面板

机柜面板模块提供直观的设备布局视图：

- **可视化展示**
  - 机柜正视图
  - 设备位置展示
  - 实时状态显示

- **设备详情**
  - 查看设备信息
  - 端口状态显示
  - 连接信息查看

## 系统配置

系统使用分层配置管理，包含以下配置文件：

### 配置文件说明

1. **config.py**：
   - 主配置文件，定义所有配置项
   - 处理环境变量加载
   - 提供默认配置值
   - 不建议直接修改此文件

2. **.env**：
   - 实际运行的配置文件
   - 包含环境特定的配置值
   - 不会提交到代码库
   - 可以根据不同环境自定义

3. **.env.example**：
   - 配置文件模板
   - 展示所有可配置项
   - 提供默认值参考
   - 用于创建实际的 .env 文件

### 配置项说明

```ini
# 服务器配置
SERVER_HOST=0.0.0.0    # 服务器监听地址
SERVER_PORT=5000       # 服务器端口
DEBUG_MODE=False       # 调试模式开关

# 数据目录
DATA_DIR=data         # 数据文件存储目录

# 其他配置
MAX_DEVICES_PER_GROUP=2  # 每个设备组最大设备数
DEFAULT_ENCODING=utf-8   # 默认文件编码
```

### 配置使用说明

1. **首次部署**：
   ```bash
   # 复制配置模板
   cp .env.example .env
   
   # 编辑 .env 文件，修改配置值
   # 例如：
   SERVER_HOST=172.31.60.204
   SERVER_PORT=58000
   DEBUG_MODE=True
   ```

2. **配置优先级**：
   - 系统环境变量 > .env 文件 > 默认值
   - 程序首先查找系统环境变量
   - 如果未找到，则使用 .env 文件中的值
   - 如果 .env 文件中也没有，则使用默认值

3. **不同环境配置**：
   - 开发环境：使用本地 .env 文件
   - 测试环境：可创建 .env.test
   - 生产环境：建议使用系统环境变量

4. **注意事项**：
   - 不要提交 .env 文件到代码库
   - 确保 .env 文件包含在 .gitignore 中
   - 修改配置后需要重启应用
   - 敏感信息（如数据库密码）建议使用环境变量

## 安装和运行

1. 克隆代码库：
```bash
git clone [repository-url]
```

2. 配置环境：
```bash
# 复制配置模板
cp .env.example .env

# 编辑配置文件
vim .env  # 或使用其他编辑器
```

3. 安装依赖：
```bash
pip install -r requirements.txt
```

4. 运行应用：
```bash
python app.py
```

5. 访问系统：
   在浏览器中打开以下链接访问各功能模块：
   - 设备管理：`http://[SERVER_HOST]:[SERVER_PORT]/device_management`
   - 连线工具：`http://[SERVER_HOST]:[SERVER_PORT]/connection_tool`
   - 机柜管理：`http://[SERVER_HOST]:[SERVER_PORT]/rack_management`
   - 机柜面板：`http://[SERVER_HOST]:[SERVER_PORT]/all_rack_panels`

## 使用说明

1. 首先在设备管理页面创建设备型号和设备实例
2. 使用机柜管理功能规划设备布局
3. 通过连线工具管理设备连接关系
4. 在机柜面板中查看整体布局和状态

## 注意事项

- 设备型号一旦被使用后将无法删除
- 已上架设备需要先下架才能删除
- 批量操作前请仔细确认选择的设备
- 建议定期备份数据
