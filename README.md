# 数据中心网络连线管理系统

这是一个用于管理数据中心网络设备连线的 Web 应用系统。该系统提供了直观的界面来管理网络设备之间的连接，支持设备组（堆叠/MLAG）的创建和管理，以及端口模板的配置。

## 主要功能

### 1. 设备连线管理
- 可视化展示设备连线状态
- 支持添加/删除设备连接
- 提供连线统计信息（总设备数、总连线数、接口利用率等）
- 支持导出连线数据（Excel/CSV格式）

### 2. 设备组管理
- 支持创建堆叠组和MLAG组
- 基于设备类型的智能分组
- 自动配置组内设备的连接（peer-link和keepalive）
- 可视化展示设备组信息

### 3. 端口模板管理
- 支持为不同设备类型创建端口模板
- 配置peer-link、keepalive、上行和下行端口
- 设置端口速率
- 灵活的端口组配置

## 技术栈

- 后端：Python + Flask
- 前端：HTML5 + Bootstrap 5 + JavaScript
- 数据存储：JSON文件

## 安装要求

- Python 3.6+
- Flask
- 其他依赖项（见 requirements.txt）

## 安装步骤

1. 克隆项目代码：
```bash
git clone [项目地址]
cd [项目目录]
```

2. 创建并激活虚拟环境（可选）：
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows
```

3. 安装依赖：
```bash
pip install -r requirements.txt
```

4. 启动应用：
```bash
python app.py
```

5. 访问应用：
打开浏览器访问 `http://localhost:5000`

## 使用说明

### 添加设备连接
1. 点击"添加连线"按钮
2. 选择源设备和目标设备
3. 选择对应的接口
4. 确认添加连接

### 创建设备组
1. 点击"管理堆叠"按钮
2. 选择组类型（堆叠/MLAG）
3. 选择设备类型
4. 选择要组建的设备
5. 确认创建组

### 管理端口模板
1. 点击"管理端口模板"按钮
2. 选择设备类型
3. 配置各类端口和速率
4. 保存模板

## 数据导出

系统支持两种格式的数据导出：
- Excel格式：包含详细的连接信息
- CSV格式：简化版连接信息

## 注意事项

1. 创建设备组前请确保已配置对应设备类型的端口模板
2. 设备组创建后会自动配置组内设备的连接
3. 删除设备组会同时删除组内的所有连接
